## 雲端伺服器是什麼？先弄清楚它怎麼運作

雲端伺服器是虛擬化出來的伺服器：供應商在自己的資料中心裡，用虛擬化技術把一台實體機器切成多台互相隔離的虛擬機，你租用其中一台，透過網路遠端使用。它跑起來的行為跟實體機幾乎一樣——裝作業系統、連 SSH、架網站、跑資料庫都行——但你不需要購買、搬運或維護任何硬體。

背後靠的是一套叫 Hypervisor 的虛擬化管理軟體。它負責把 CPU、記憶體、儲存空間分配給每台虛擬機，而且彼此隔離：隔壁用戶的主機忙翻天，也不會吃掉你的資源。分工很明確，機房、硬體、網路歸供應商管，作業系統之後的一切歸你管。

順帶一提，市面上還有公用雲、私有雲、混合雲的分法。對個人用戶和大多數中小企業來說，實際用到的就是公用雲。

### 跟傳統實體伺服器差在哪

| 比較項目 | 傳統實體伺服器 | 雲端伺服器 |
| --- | --- | --- |
| 設備 | 真實機器，有產權 | 虛擬機，無實體 |
| 位置 | 公司機房或代管中心 | 供應商資料中心，遠端存取 |
| 容量 | 買定離手，升級要動硬體 | 按需調整，可升可降 |
| 備份 | 自己加裝硬碟規劃 | 控制台設定，自動同步 |
| 硬體故障 | 自己修或找廠商 | 供應商負責 |

一句話收尾：除非法規要求資料必須留在自己控制的實體設備裡，否則雲端方案在成本和彈性上通常都占上風。

## 雲端伺服器好在哪？四個對使用者真正有意義的好處

對使用者來說，雲端伺服器的價值集中在四件事上：

- 彈性擴縮：流量漲了升級規格，旺季過了再縮回來，幾分鐘搞定，不用走採購流程
- 租用制計費：用多久付多久，入門月費可以低到幾美元，不必一次押注多年的硬體投資
- 免維護：硬體故障、機房斷電、線路出狀況，都是供應商的責任範圍
- 高可用：有規模的供應商會做多點備援，單一機器故障，服務能自動轉移繼續跑

這些好處不是每家供應商都給得足，差別主要落在價格結構和管理方式，也就是下一節的主題。
